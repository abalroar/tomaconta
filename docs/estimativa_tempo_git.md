# Estimativa diária de tempo trabalhado (base GitHub)

## Metodologia usada
- Fonte: histórico de commits do Git (`git log`), ignorando merges.
- Uma sessão ativa é encerrada quando há **mais de 90 min** sem commit ou muda o dia.
- Duração de cada sessão = intervalo entre 1º e último commit da sessão + **15 min** de buffer.
- Duração mínima por sessão: **20 min**.
- Duração máxima por sessão: **4h** (evita inflar sessões muito longas sem evidência).
- Esta é uma estimativa conservadora para apresentação gerencial, não um apontamento oficial de horas.
